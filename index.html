(05)RULES

Rules you set once, and the system keeps.

Marks and limits live in a file in your vault, not on a server. Agents read them but cannot change them: only you can edit them.

01

A trial period that counts

Before evaluation, the agent must complete a minimum number of days and paper trades. No shortcuts, even after a spectacular start.

MIN DAYSMIN TRADES
02

A drawdown that is not negotiable

You set how far the agent's account may fall from its peak. Cross it and the agent pauses instantly, on paper or live.

YOU SET ITAUTO PAUSE
03

Only what the strategy allows

Each agent trades the assets, hours and sizes in its strategy note. An order outside it is blocked before it is sent.

ALLOWED ASSETSMAX SIZE
04

Capital in tiers

The first real money is small. Each next tier means beating the marks again with the previous tier's capital.

TIEREDYOU SET THE CEILING
05

A daily loss limit

If the agent hits the day's max loss, it stops trading until tomorrow. Your vault's anti-tilt rule, applied to a machine.

PER DAYNO REVENGE
06

Two models agree, or nothing happens

In Team mode, every trade one model proposes is reviewed by a different model against your vault. Both notes link to the trades of yours that justify it.

(06)YOUR CONTROL

What an agent can never do.

Automation usually means handing over the keys. Here agents read, learn and trade inside a box you draw, and the move to real money always goes through you.

01

Change your marks

The rules file is read-only for agents. If an agent wants different marks, it proposes them in a note and you decide.

02

Withdraw or move money

Broker keys can only trade. No agent can withdraw funds or transfer them to another account.

03

Beating the marks only puts the agent on hold. Until you confirm, it stays on paper.

04

Every order is written to the vault before it is sent. If it is not in your journal, it did not happen.

(07)HOW IT WORKS

From a note to a live account.

Four stages, the same for one strategy or ten, run by the same team.

01JOURNAL

Write down your trades

Use the vault template: asset, entry, stop, exit, PnL, thesis, how you felt and what you would do differently. Import your history if you already have one.

02LEARN

The team reads you

Opus finds where you win and lose, Fable spots your psychology patterns, Gemini and Grok add the market around you. GPT challenges every idea before it becomes a strategy.

03PAPER TRADING

They prove it on paper

Each agent trades a simulated balance for the period you set. Brake enforces your limits and everything is written to the vault.

04REAL MONEY

They beat the marks, you decide

If it meets your marks, the agent asks you for a first capital tier. You approve, and it keeps being evaluated every day with real money.

(08)THE TEAM

Models that check each other's work.

No leaderboard and no winner-takes-all. Each model does the job it is best at, and in Team mode every trade needs a second model to agree. Prefer one model? Switch to Solo. You choose which models are on.

(10)GET THE APP

It runs on your computer, next to your vault.

Your journal, your API keys and your Kraken key never leave your machine, so the app is installed locally instead of living on this website.

Download for macOS ↓ Windows ↓ Linux ↓

Installers are unsigned for now. On macOS: right-click the app, choose Open, then Open again. On Windows: More info, then Run anyway.

Or run it from source

01

Install Node.js

Version 20 or newer, from nodejs.org. Nothing else is needed: the app has no dependencies.

02

Download agentsIA

Get the code from GitHub and open the folder in a terminal.

git clone https://github.com/neoonchain/agentsIA
cd agentsIA
03

Start it

Then open localhost:4317/app in your browser. Your vault is created in ~/TradingVault; open it in Obsidian.

npm start
